## 1. 프론트 앱 구조 요약

| 앱 | 스택 | 빌드 커맨드 | 산출물 | 기동 방식 |
|---|---|---|---|---|
| web   | React Router 7 + Vite | `react-router build` | `build/client/` (SPA 정적) + `build/server/` (미사용) | Caddy 정적 서빙 (Phase 7) |
| admin | 동일 | 동일 | `build/client/` | 동일 |
| space | 동일 | 동일 | `build/client/` | 동일 |
| live  | Node + tsdown (Yjs/Hocuspocus) | `tsc --noEmit && tsdown` | `dist/start.mjs` | NSSM `node dist/start.mjs` (Phase 6) |

**SPA vs SSR**: React Router 7 을 "SPA 모드" 로 사용. `build/client/` 만 정적 서빙하면 된다. `build/server/` 는 Node SSR 엔트리지만 본 배포에서는 사용하지 않음.

**주의 — vite.config.ts 의 env 로딩**:
```ts
dotenv.config({ path: path.resolve(__dirname, ".env") });
const viteEnv = Object.keys(process.env).filter(k => k.startsWith("VITE_")).reduce(...);
define: { "process.env": JSON.stringify(viteEnv) },
```
→ 빌드 시점에 `apps/*/.env` 가 반드시 존재해야 하며, `VITE_*` 만 SPA 번들에 포함. **Phase 5 시작 전에 §2 로 `.env` 생성 필수**.

## 2. `render-envs.ps1` 확장

Phase 2 에서 만든 스크립트의 `# Phase 5 에서 아래 주석을 해제` 블록을 실제 섹션으로 대체.

`D:\Workspace\plane-app\ops\render-envs.ps1` 의 API 섹션 이후에 다음을 추가:

```powershell
# ─── apps/web/.env ───
$webEnv = @"
# AUTO-GENERATED by ops/render-envs.ps1
VITE_API_BASE_URL=$base
VITE_WEB_BASE_URL=$base
VITE_ADMIN_BASE_URL=$base
VITE_ADMIN_BASE_PATH=/god-mode
VITE_SPACE_BASE_URL=$base
VITE_SPACE_BASE_PATH=/spaces
VITE_LIVE_BASE_URL=$base
VITE_LIVE_BASE_PATH=/live
"@
$webEnv | Set-Content -Path (Join-Path $AppRoot "apps\web\.env") -Encoding UTF8 -NoNewline
Write-Host "Rendered: apps\web\.env"

# ─── apps/admin/.env  (web 과 동일 키) ───
$webEnv | Set-Content -Path (Join-Path $AppRoot "apps\admin\.env") -Encoding UTF8 -NoNewline
Write-Host "Rendered: apps\admin\.env"

# ─── apps/space/.env  (web 과 동일 키) ───
$webEnv | Set-Content -Path (Join-Path $AppRoot "apps\space\.env") -Encoding UTF8 -NoNewline
Write-Host "Rendered: apps\space\.env"

# ─── apps/live/.env  (Node env, VITE_* 아님) ───
$liveEnv = @"
# AUTO-GENERATED by ops/render-envs.ps1
PORT=3100
API_BASE_URL=$base
WEB_BASE_URL=$base
LIVE_BASE_URL=$base
LIVE_BASE_PATH=/live
LIVE_SERVER_SECRET_KEY=$($vars.LIVE_SERVER_SECRET_KEY)
REDIS_URL=redis://:$($vars.REDIS_PASSWORD)@127.0.0.1:6379/0
"@
$liveEnv | Set-Content -Path (Join-Path $AppRoot "apps\live\.env") -Encoding UTF8 -NoNewline
Write-Host "Rendered: apps\live\.env"
```

### 2.1 재렌더

```powershell
cd D:\Workspace\plane-app\ops
.\render-envs.ps1
# Rendered: D:\Workspace\plane-app\apps\api\.env
# Rendered: apps\web\.env
# Rendered: apps\admin\.env
# Rendered: apps\space\.env
# Rendered: apps\live\.env
```

### 2.2 경로 이슈 — 단일 도메인 라우팅

모든 프론트 `VITE_*_BASE_URL` 이 동일 `$base` (공인 IP 또는 도메인)을 가리키고, `*_BASE_PATH` 로만 분기. Phase 7 Caddy 가 path prefix 로 각 SPA 를 분기 서빙 (`/god-mode/*`, `/spaces/*`, `/live/*`, 기본은 web).

포트 충돌 방지: 개발 시에만 포트 구분(`3000/3001/3002`), 운영에서는 **Caddy 가 단일 80 포트**로 수신하고 path prefix 로 정적 SPA 디렉토리를 분기.

## 3. 빌드 실행

### 3.1 전체 빌드

```powershell
cd D:\Workspace\plane-app
pnpm turbo build --filter=web --filter=admin --filter=space --filter=live
```

Turbo 가 의존 `@plane/*` 패키지들을 먼저 빌드한 뒤 앱 빌드 — 15~20분 소요 (첫 빌드), 이후 cache hit 시 2~3분.

### 3.2 산출물 검증

```powershell
Test-Path "D:\Workspace\plane-app\apps\web\build\client\index.html"
Test-Path "D:\Workspace\plane-app\apps\admin\build\client\index.html"
Test-Path "D:\Workspace\plane-app\apps\space\build\client\index.html"
Test-Path "D:\Workspace\plane-app\apps\live\dist\start.mjs"
```

4개 모두 True 여야 함.

### 3.3 `VITE_*` 주입 검증

빌드된 번들에 `$base` 가 inline 되었는지 확인:

```powershell
Select-String -Path "D:\Workspace\plane-app\apps\web\build\client\assets\*.js" `
  -Pattern "222\.234\.220\.199" -Quiet
# True — PUBLIC_HOST 값이 번들에 포함됨
```

→ 도메인 전환(`site.env` 변경 + render-envs 재실행) 시 **재빌드 필수**. Phase 7 에서 이를 자동화하는 경우 별도 메모.

## 5. 정적 서빙 전략 (Phase 7 로 연결)

빌드 산출물 위치를 Phase 7 Caddy 에 고정하기 위해 본 Phase 에서 결정:

| 경로 | 역할 |
|---|---|
| `D:\Workspace\plane-app\apps\web\build\client\`   | `/*` (fallback) |
| `D:\Workspace\plane-app\apps\admin\build\client\` | `/god-mode/*` |
| `D:\Workspace\plane-app\apps\space\build\client\` | `/spaces/*` |
| (API 프록시) | `/api/*`, `/auth/*`, `/static/*`, `/uploads/*` → `http://127.0.0.1:8000` |
| (Live 프록시) | `/live/*` → `http://127.0.0.1:3100` (WebSocket upgrade) |

SPA 라우팅 fallback: `/*` → `index.html` (React Router client-side routing).
